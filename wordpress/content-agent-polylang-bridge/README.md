# Content Agent Polylang Bridge

إضافة ووردبريس صغيرة تسمح للنظام بنشر المقال نفسه بعدة لغات عبر Polylang.

النسخة المجانية من Polylang لا تتيح عبر REST API تحديد لغة المقال أو ربط الترجمات ببعضها. هذه الإضافة تضيف ذلك:

- حقل `lang` على المقالات والصفحات وأنواع المحتوى المترجمة (مثل الخدمات) والتصنيفات والوسوم (قراءة وكتابة).
- حقل `translations` على المقالات: `{ "ar": 12, "en": 34 }` لربط الترجمات ببعضها.
- فلتر `?lang=en` عند البحث عن التصنيفات والوسوم والمقالات.
- endpoint للاختبار: `/wp-json/content-agent/v1/polylang` (يرجع اللغات المفعّلة).

إذا كان Polylang Pro مفعّلًا فلن تسجّل الإضافة الحقول (Pro يوفّرها) وتكتفي بـ endpoint الاختبار.

## التثبيت

1. ثبّت وفعّل Polylang (النسخة المجانية 3.7 أو أحدث) وأضف لغات الموقع.
2. من لوحة ووردبريس: إضافات -> أضف جديد -> رفع إضافة، وارفع `content-agent-polylang-bridge.zip`.
3. فعّل الإضافة.
4. من النظام افتح المواقع واختر "مزامنة اللغات"، ثم اختر اللغات التي تريد النشر بها.

## المتطلبات

- WordPress 6.0 أو أحدث، وPHP 7.4 أو أحدث.
- مستخدم ووردبريس (Application Password) لديه صلاحية تحرير المقالات.
